# Opções

Leia este arquivo só no passo 3, na mesma sessão do brief. Acrescente `## Opções` em `work/<id>/brief.md`.

Adaptado de `skills/brainstorm/SKILL.md` do rabbitOS (an internal sibling project). Não é cópia. Ficou de fora o que é só de lá: `intent.sh`, roadmap, classes spike/bounded, walkaway e o plugin superpowers. A crítica de outro provedor é a skill `revisar-spec`.

## O que gravar
Dois ou três caminhos distintos. Cada um tem nome, trade-off e critério de pronto. Pesquisar a solução padrão (o que já existe pronto, com a fonte) é um caminho válido.

A opção recomendada é a primeira. O dono escolhe pela ferramenta de pergunta, uma vez. Sem a escolha, pare. A spec fica para a skill `spec`, a partir do caminho escolhido.

```
## Opções
1. <nome> — recomendado. Trade-off: <uma linha>. Pronto quando: <comando ou fato>.
2. <nome>. Trade-off: <uma linha>. Pronto quando: <comando ou fato>.
3. <nome, opcional>. Trade-off: <uma linha>. Pronto quando: <comando ou fato>.

Escolha: <a que o dono marcou>
```
