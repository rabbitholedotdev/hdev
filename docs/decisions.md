- 2026-11-21: REL-082. Mudar o manifesto de hooks muda o `.claude/settings.json` que cada app tem no git: a release que faz isso quebra o `hdev check` dos apps (linha `sync`) até cada um rodar `hdev sync` e commitar. Antes de promover, o `hdev check` roda num clone do app com o `.harnessdev` apontando para a release nova: o bin novo dentro do app ainda lê o manifesto pelo `.harnessdev` antigo.
